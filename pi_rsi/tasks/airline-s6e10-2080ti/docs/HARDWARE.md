# Hardware and reproducibility

Only physical GPU index **1**, UUID **GPU-2c54fc50-8962-5ef4-a42f-45752aedef9d**, NVIDIA GeForce RTX 2080 Ti, 11 GB VRAM, is authorized. Physical GPU 0 is an RTX 3090 and is prohibited.

The caller supplies `CUDA_DEVICE_ORDER=PCI_BUS_ID` and the single authorized UUID in `CUDA_VISIBLE_DEVICES`. Never unset/expand the mask. Within this mask use **logical CUDA 0**, not logical device 1. The harness queue uses `RSI_GPUS=1`, assigning physical index 1 and writing mask `1`; the guard accepts only this exact single-index mask or the supplied UUID. It never changes visibility. The independently queried physical UUID/index/name/VRAM must match, and CUDA Driver API must see exactly one device with that UUID/name at logical index 0. Any discrepancy fails closed before fitting. `nvidia-smi` identification does not launch compute on GPU 0.

CPU preprocessing is capped at 8 threads via environment and CLI. Frozen evaluation also restricts child CPU affinity to at most 8 allowed CPUs. Candidates must respect the cap across all their preprocessing/fitting code and not evade affinity or spawn services. GPU CatBoost uses `task_type='GPU'`, `devices='0'`, 0.85 GPU RAM fraction; no CPU fallback. Avoid GPU allocations over the card's 11 GB limit.

Measured on 2026-10-04: CUDA driver 595.71.05, 11264 MiB reported by nvidia-smi, matching physical/logical UUID. CatBoost 1.2.10, Python 3.12.3. Actual GPU fits used 400 depth-6 trees, Plain boosting with one-hot encoding of low-cardinality categories. Measured quick fit 2.145s, validation fit 2.573s; externally measured whole-CLI 3.588s and 4.845s. Exact metrics in `docs/BASELINE.json`; no final run was performed.

Split and model seeds are 20261004. GPU CatBoost parallel floating-point reductions are **not bitwise deterministic**. Prediction/model hashes and tiny score changes may differ even at fixed seeds. The reference table records one measurement per level. A quick wrapper integration repeat scored 0.9525372110676713 instead of 0.9525373326142100 at the same seed, with fit 1.878s, whole candidate 2.785s and evaluator routine 3.040s. This small difference illustrates GPU variation, not a statistically reliable dispersion/uncertainty estimate. Evaluator-routine timers exclude evaluator interpreter/import startup. Do not claim zero uncertainty or significance from an unmeasured difference. Later well-motivated hypotheses may use predeclared repeated seeds and ablations within their three development trials.

Use only pinned packages already present in the local uv cache. `setup.sh` creates a task-local .venv using uv/Python 3.12 and installs offline; no global changes or downloads. Keep the caller's CUDA variables and isolated RSI_JOBS_DIR unchanged. Do not start a separate daemon, supervisor, orchestration loop, or research experiment during task preparation.
