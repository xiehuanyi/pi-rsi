This is pi-rsi’s own explorer for the airline run. It holds far more detail than the overview, which is the better place to start if you want the story first. Below is a short guide to the six panels, then a few nodes worth opening.

How to read this page

  1. Summary stripBaseline and best official scores, hypotheses allocated against the 32-node limit, execution attempts including retries, and an estimate of model-API spend. GPU time is not included.
  2. Search treeDrag to pan, scroll or use +/− to zoom, and press Best to jump to the top node. Each card shows the official score and the gain over its parent. Card colour is the auditor’s verdict; the gold path is the best node’s ancestry and the dashed path is the selected node’s.
  3. InspectorThe selected node in depth. Overview has the hypothesis, observed result, recorded code changes and the auditor’s claim check. Handoff is what the worker left for the next agent. Result analysis, Progress and Evidence hold the analyst’s reading, the worker’s running log and the linked Wiki evidence.
  4. Score curveThe same best-so-far curve as the overview. Switch to By time to see wall-clock pacing, including idle gaps. Crosses mark failed nodes.
  5. Research knowledgeInsights and Dead ends are ledgers in which every line cites the node that produced it. Wiki & revisions shows the Wiki at the revision pinned to this snapshot.
  6. Node ledgerOne row per node: verdict, official score, gain over its parent (green up, red down), elapsed time and parent. Search or filter by status, and click an id to select that node everywhere on the page.

Why does almost every node say “no change”?

The auditor labels a node improved only when its gain over its parent exceeds a noise threshold. This evaluator reports a single AUC without per-row uncertainty, so the harness falls back to a deliberately conservative default of 1% of the baseline score, about 0.0096 AUC. No single step in this run comes close. Read “no change” as “not distinguishable under the default rule,” and use the Gain vs parent column together with the agent’s +0.0002 practical bar for finer judgement.

Good places to start

  • The best node. Open its Handoff tab to see how the worker described its own below-threshold result.
  • The largest single step, depth 8 with L2 = 10, and the parent of six follow-up hypotheses.
  • A fresh control that reproduced n014’s score in every recorded digit.
  • A voided measurement: the model file changed after it was scored.
  • A crash with a recorded diagnosis. Its repaired follow-up is n013.
