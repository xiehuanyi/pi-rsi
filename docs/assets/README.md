# Architecture artwork

Original pi-rsi illustrations in English and Chinese, with light and dark themes. The README uses SVG for sharp text at any zoom; PNG copies provide convenient previews.

The phase / feedback / inset presentation was informed by [Dream-RSI's overview](https://github.com/zhengkid/Dream-RSI). These figures depict pi-rsi's own experiment and evidence workflow; the Wiki and task-monitor branch refers to the development runtime used in the airline example.

Regenerate the editable vector files from the repository root:

```sh
python3 scripts/render_architecture.py
```
